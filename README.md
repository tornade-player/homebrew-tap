# homebrew-tap

Official Homebrew tap for [Tornade](https://tornade.tf), a native FLAC and lossless audio player.

## Install

```bash
brew tap tornade-player/tap
```

### Tornade (macOS app)

```bash
brew install --cask tornade
```

### Tornade TUI (terminal player, macOS and Linux)

```bash
brew install tornade-tui
```

## Formulae and casks

| Name | Type | Platform | Source |
|---|---|---|---|
| `tornade` | cask | macOS | [tornade-gui](https://github.com/tornade-player/tornade-gui) |
| `tornade-tui` | formula | macOS, Linux | [tornade-tui](https://github.com/tornade-player/tornade-tui) |
